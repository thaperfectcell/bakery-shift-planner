# ООП-реализация на Java (КТ3)

Та же программа, что процедурная версия на Python из каталога `src` (КТ2), но в объектно-ориентированном стиле:
сводит заявки на дату отгрузки, корректирует план выпуска, рассчитывает потребность в сырье (алгоритм 1),
сверяет её с остатками склада, распределяет партии по печам и сменам (алгоритм 2) и формирует сменные задания
и требование-накладную. На одних и тех же данных обе версии выводят одинаковый результат.

## Требования

- JDK 25 (LTS), проверено на Temurin 25.0.5.
- Apache Maven 3.10.0 (подойдёт любой 3.9+). Без Maven программу можно собрать одним `javac` (см. ниже).
- Внешних библиотек нет; JUnit 6.1.3 нужен только для тестов, Maven скачает его сам.

## Сборка и запуск через Maven

Из каталога `src/java`:

```
mvn package
java -jar target/bakery-shift-planner.jar
```

`mvn package` компилирует код, прогоняет тесты и собирает `target/bakery-shift-planner.jar`.

## Сборка без Maven (только javac)

Windows PowerShell, из каталога `src/java`:

```
javac -encoding UTF-8 -d build/classes (Get-ChildItem -Recurse src/main/java -Filter *.java).FullName
java -cp build/classes ru.mirea.bakery.app.Main
```

Linux, macOS или Git Bash:

```
javac -encoding UTF-8 -d build/classes $(find src/main/java -name "*.java")
java -cp build/classes ru.mirea.bakery.app.Main
```

## Параметры

| Параметр | Назначение | По умолчанию |
|---|---|---|
| `--data КАТАЛОГ` | каталог с исходными CSV-файлами | `data` |
| `--date ГГГГ-ММ-ДД` | дата отгрузки | ближайшая дата в заявках |
| `--out КАТАЛОГ` | каталог для результатов в CSV | `out` |

## Тесты

```
mvn test
```

12 тестов проверяют рекурсивное раскрытие рецептур, пересчёт муки на влажность, обнаружение циклической
ссылки, правило отсечки заявок, чтение CSV со значениями в кавычках, распределение партий при перерывах
между сменами и совпадение результатов с процедурной версией на демонстрационных данных: консольного
вывода (`src/test/resources/expected_output.txt`) и всех шести файлов CSV (`src/test/resources/expected/`).
Эталоны получены командой `python main.py --data data --out <каталог>` из каталога `src`.

## Структура

| Пакет | Содержимое |
|---|---|
| `ru.mirea.bakery.model` | сущности логической модели: `Customer`, `DeliveryPoint`, `Order`, `OrderItem`, `Product`, `Recipe`, `RecipeComponent` и его подклассы `MaterialComponent`, `SemiProductComponent`, `Material`, `StockRecord`, `Oven`, `Shift`, `ShiftTask`, `Batch`, а также `Delivery` и `MaterialRequirement` |
| `ru.mirea.bakery.planning` | операции процесса: `OrderRegistry`, `Demand`, `ProductionPlan`, `Warehouse`, `BakeryFloor`, `Requisition`, `ShiftPlanningProcess` |
| `ru.mirea.bakery.rules` | интерфейс `OrderRule` и правила проверки заявки: `KnownDeliveryPointRule`, `NonEmptyOrderRule`, `OrderItemsRule`, `CutoffTimeRule` |
| `ru.mirea.bakery.io` | чтение CSV (`CsvDataSource`), интерфейс `ResultWriter` и его реализации `ConsoleReportWriter`, `CsvResultWriter` |
| `ru.mirea.bakery.app` | точка входа `Main` |

## Входные данные

Каталог `data` - те же CSV-файлы, что и у процедурной версии (`src/data`): по файлу на каждую сущность
логической модели, разделитель - точка с запятой, кодировка UTF-8. Пример - заявка Z001 и её позиции:

```
order_id;point_id;ship_date;channel;received_at
Z001;D01;2026-11-05;EDI;2026-11-04 09:12

order_id;product_id;quantity
Z001;P01;540
Z001;P02;300
Z001;P03;600
Z001;P05;360
```
