## О проекте

Программное средство для промышленной пекарни (хлебозавода), которое по заявкам покупателей:

- сводит заявки в план выпуска с округлением до кратности технологических партий;
- рассчитывает потребность в сырье по рецептурам с учётом полуфабрикатов и влажности муки;
- сверяет потребность с остатками сырья на складе;
- распределяет партии изделий по печам и сменам;
- формирует сменные задания и требование на отпуск сырья.
