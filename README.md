## О проекте

Программное средство для промышленной пекарни (хлебозавода), которое по заявкам покупателей:

- сводит заявки в план выпуска с округлением до кратности технологических партий;
- рассчитывает потребность в сырье по рецептурам с учётом полуфабрикатов и влажности муки;
- сверяет потребность с остатками сырья на складе;
- распределяет партии изделий по печам и сменам;
- формирует сменные задания и требование на отпуск сырья.

Задача реализована дважды: процедурно на Python (КТ2) и объектно-ориентированно на Java (КТ3).
На одних и тех же входных данных обе версии дают одинаковый результат.

## Структура репозитория

```
docs/             отчёты по контрольным точкам
docs/models/      диаграммы: BPMN, ER, схемы алгоритмов, диаграмма классов UML
docs/translation/ перевод иностранного источника (КТ1)
src/              процедурная реализация на Python (КТ2), запуск: python main.py
src/data/         демонстрационные данные в CSV
src/java/         объектно-ориентированная реализация на Java (КТ3), см. src/java/README.md
```

## Запуск

```
cd src
python main.py --date 2026-11-05

cd src/java
mvn package
java -jar target/bakery-shift-planner.jar --data data --date 2026-11-05
```
